## Установка

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. ffmpeg
sudo apt install ffmpeg   # Linux
# Windows: https://ffmpeg.org/download.html

# 3. Настройка .env
cp .env.example .env
# Заполните ключи

# 4. Google Sheets (опционально)
# Создайте Service Account на https://console.cloud.google.com
# Скачайте JSON → сохраните как google_credentials.json
# Создайте таблицу, дайте доступ service account
# GOOGLE_SHEET_ID → в .env

# 5. Проверка
python test.py

# 6. Запуск
python main.py
```

## Google Sheets настройка

1. Идите на https://console.cloud.google.com
2. Создайте проект → включите Google Sheets API и Google Drive API
3. IAM → Service Accounts → Create → скачайте JSON ключ
4. Сохраните ключ как `google_credentials.json` в папку проекта
5. Создайте Google Таблицу → поделитесь с email из JSON ключа
6. ID таблицы (из URL) добавьте в `.env` как `GOOGLE_SHEET_ID`

Бот автоматически создаст листы: **Лиды**, **Тест-драйвы**, **Покупки**

## Обучение

```bash
python learn.py           # меню
python learn.py --show    # статистика
python learn.py --auto    # авто-импорт из истории
python learn.py --unknown # ответить на неизвестные вопросы
```

При каждом запуске `main.py` бот **автоматически** обучается на переписках менеджеров.

## Сегментация клиентов

Бот автоматически определяет:
- **НОВЫЙ** — первое обращение, представляется, выявляет потребности
- **ПОТЕНЦИАЛЬНЫЙ** — интересовался, продолжает работу по продаже
- **ДЕЙСТВУЮЩИЙ** — уже купил авто, предлагает помощь с обслуживанием

Пометить вручную:
```python
from ai_handler import mark_customer_purchased
mark_customer_purchased(chat_id=123456789, model="Voyah Courage")
```

## Структура файлов

```
main.py                 — запуск бота
ai_handler.py           — ИИ, промпты, расчёт кредита
storage.py              — история, обучающие данные
sheets_handler.py       — Google Sheets интеграция
voice_handler.py        — голосовые сообщения
learn.py                — скрипт обучения

history.json            — история диалогов
training_data.json      — обучающие примеры
customer_status.json    — статусы клиентов
unknown_questions.json  — вопросы без ответа

google_credentials.json — ключ Google Service Account
local_leads.json        — лиды (если нет Google Sheets)
local_test_drives.json  — тест-драйвы (если нет Google Sheets)
```
